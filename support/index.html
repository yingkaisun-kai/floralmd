常见问题

为什么文件无法导入？

FloralMD 1.0 接受非空的 UTF-8 `.md` 和 `.markdown` 文件。 请确认文件扩展名、文本编码，并检查文件是否包含内容。

FloralMD 会修改原文件吗？

不会。App 保存一份只读的本地离线副本，原始文件保持不变。

文档中的远程图片或嵌入内容为什么没有显示？

FloralMD 不加载远程图片或嵌入内容。原始 HTML 会作为文本显示， 避免文档在阅读时发起未预期的网络请求。

如何把文档发回其他 App？

使用分享功能即可分享原始 Markdown。分享只会在你主动选择后发生。

FloralMD for iOS

Support

If FloralMD is not working as expected or you have a question about the reading experience, email us at floralmd.help@outlook.com.

What to include

  • Your device model and iOS version;
  • Your FloralMD version;
  • The steps that led to the issue;
  • A screenshot only when needed and checked for private content.

Please do not send private or sensitive Markdown documents. If a problem depends on a particular file, create a minimal example with personal information removed.

Import requirements

FloralMD 1.0 accepts non-empty UTF-8 `.md` and `.markdown` files. It keeps a read-only, offline copy and does not modify the source file.

Remote content

Remote images and embedded content are not loaded. Raw HTML is shown as text so reading a document does not trigger unexpected network requests.
